About

From C++ and Java in Office for Android to Viva Learning and cloud storage at Microsoft.

03 / strata · move to explore

I joined Microsoft as an engineer on the Android versions of Word, Excel and PowerPoint, writing shared C++ and Java that ran in all three apps. A lot of that work was below the UI: rendering threads, file I/O, printing, licensing, and the time it takes to boot the app and open a file. When something crashed in native code, debugging JNI bridges and C++ stack traces was part of the job.

Next was Office Mobile, an effort to combine the three apps into one. It launched first in China with a small team, earned the case for a larger one, and then shipped worldwide.

After that I was part of the founding team of Microsoft Viva Learning, building it from an empty repository to a shipped product on a React and full-stack architecture.

Today I lead a team in OneDrive and SharePoint Storage, working on blob storage, data migration pipelines and governance for enterprise customers.

Most of what I’ve learned has come from moving between layers — native, web and cloud — and from shipping with good teams.
